### Skills
Skills are a standardized way to give AI agents new capabilities and expertise. There are a few skills that are a must have.

[Ponytail](https://ponytail.dev) is a plugin for AI agents to write the least code possible. It stops them from pulling in unnecessary dependencies, using the standard library wherever possible and reducing the code that's written. It stops from AI agents going off the hook and writing new code everytimg a user requests something.

#### React

React Best Practices is a skill designed by Vercel Labs to teach agents the latest React patterns. Follows the official React documentation and community best practices.

```sh
npx skills add vercel-labs/agent-skills@vercel-react-best-practices
```

#### ShadCN/UI

ShadCN is the most popular component library and which you're most likely to use in your application. 

```sh
npx skills add shadcn-ui/ui@shadcn
```
