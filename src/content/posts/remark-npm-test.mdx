This is a short sample post for verifying the `remarkNpm` plugin from
`fumadocs-core/mdx-plugins`. The single fenced `npm` block below should be
replaced with a tabbed code block showing all four package managers.

```npm
npm install some-package
```

Click through each tab above and confirm the command is converted correctly,
for example that the yarn tab reads `yarn add some-package`.
